## Mobile verification and corrections

Checked the live Index with Chromium and WebKit touch emulation at 320, 390 and 430px. Mobile search uses 16px text to avoid small-input focus zoom on iPhone, and the clear, OPEN, related-name and photo-close controls have 44px touch targets. The photo dialog fits within the screen. Browser Back restores the list/search position; same-site OPEN destinations use the current tab. Desktop typography and category/column ordering are preserved.
